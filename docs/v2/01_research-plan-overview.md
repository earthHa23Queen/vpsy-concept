## 1. VPSYとは

VPSYは、一般に感情と呼ばれる現象を時刻Tで分解し、記憶・環境・性格などの多要素と接続した、感情のシミュレーション装置の構想です。  
14〜15歳頃に構想を始め、19〜22歳頃に骨組みのほとんどを作り、エンジニアになってから技術的な部分を足してきました。  

立場は、感情の再現ではなく模倣です。  
目的は、誰かを理解することではなく、誰かを理解する一助、人が判断する材料の一欠片となることです。  

---

## 2. 読むときの前提

これまでの検討で、次の三点を知らずに読むと、主張を取り違えやすいことがAIを使った作業によって分かっています。  

1. **VPSYの語はモジュール名である。**  
感情、気分、気持ち、観念、傾向性などは、システムのモジュールにあてがった名前で、一般の意味や心理学の専門用語とは一致させていない。  
先行研究とは、語の文字列ではなく機能で照合している。  
たとえば、心理学で感情（emotion）と呼ばれ数分以上続くものは、機能としてVPSYの「気持ち」に当たる。  
VPSYの「感情」は、その下にある数秒単位の層である。  
2. **技術は構造だけを借りている。**  
TCP/IP、TTL、サブネット、ハフマン符号化などは、論理の構成や分け方を借りてVPSY向けに広げたもので、技術そのものの性質（例：ハフマン符号化は可逆）を主張に持ち込んではいない。  
3. **強い言い切りは、考え抜いた限界点の表明である。**  
「常に」「実在できない」などの表現は、例外を暗黙に前提したうえで、ここではこう捉える、という意味で使っている。

## 3. 研究の問いと判定

**主な問い**：一般に感情と呼ばれる現象を時刻Tで分解し多要素と接続したモデルは、心理学研究の結果と過程をどこまで模倣できるか  

**副次的な問い**  

- そのモデルにおいて、性格は有限のパターンに収束するか
- 睡眠のように先行研究で決着していない処理を、先行研究の結果と軋轢を生まない範囲で、どこまでセンチネル値のような簡略的な処理で扱えるか

**一番上の要求**：  
心理学研究の結果と、研究が示す心理の過程に対して、VPSYの結果と各層の途中の値を照合でき、その一致と差異を示せる、感情のシミュレーション装置であること  

**判定**：結果と過程の2軸で、4通りに分ける。  

| 結果 | 過程 | 意味 |
| --- | --- | --- |
| 同じ | 似ている | 装置が妥当に動いている証拠 |
| 違う | 似ている | 研究結果の誤りや、一般化の限界の可能性を示唆する |
| 同じ | 違う | 偶然の一致。妥当とは言えない |
| 違う | 違う | 装置の側の見直しが必要 |

## 4. 構成の要点

| モジュール | 働き | 時間 |
| --- | --- | --- |
| 情報 | 外部入力・記憶・環境の総合 | 時刻tごと |
| 観念・理解力 | 情報の抽象化と、その検証・重み付け | 無意識 |
| 傾向性 | 観念から感情への変換の触媒。個人差を担う | 時間管理の外から内への変換 |
| 感情 | 傾向性の出力。範囲として同じ値で再生起すれば持続する | 一瞬〜数秒 |
| 気分 | 感情の連続と状況から成る | 感情より長い |
| 気持ち | 気分の持続。心理学の感情エピソードに当たる | 気分より長い |
| 記憶 | エピソードと、そのときの出力・環境の記録。短期記憶→長期記憶→過去→昔と非可逆に圧縮される | 日付単位以上 |
| 環境 | 処理全体へのバイアス。sentimentもまずここに入り、時間をかけて傾向性・観念になる | 永続的 |
| 性格 | 一定期間の傾向性の出力パターンの言語化 | 任意の区間 |

感情→気分→気持ちの移行は、TTL（有効時間）の中での再生起と閾値で段階的に起きる。  
環境は、社会的問題やマイノリティの属性の側が値を持ち、経験が無いデフォルトは平常値を持たない向きで表す。

## 5. 先行研究との関係

28の仮説を、10回の調査で先行研究と機能で照合した。対立が残った仮説はなかった。  

**既知の部分**：短い層の出力が長い層を動かす直列の構成（ALMA、WASABI、Soarに基づくモデル）、性格を状態の分布とする見方（Fleeson、CAPS）、感情の文脈とともに符号化し想起で書き換わる記憶（CMR3）、逆境の累積の測り方（ACE）など。  

**VPSYに固有と言える部分**  

- 心理学の感情（emotion）を最上層の気持ちに当て、その下に数秒の感情を置く3層の対応付け
- 範囲（サブネット）としての一致とTTLによる段階的な遷移
- 記憶と環境を別のバイアス源として分けること、sentimentが環境から傾向性・観念へ形成される順序
- 正常値を反転させた計測の向きを、感情のシミュレーションの基礎にすること
- 各層の途中の値の照合を、一番上の要求の段階から組み込んだこと

**最も照合しやすい点**：感情の再生起による持続（H03）。誘発刺激の再出現や反すうで感情エピソードが延びること、強度の推移の山の数、終点の定義による持続時間の違い（中央値2時間と5時間）などの実測データ（Verduynらの一連の研究）と、機能として直接対応する。  

**位置付け**：既存研究をソフトウェアの中で実体として接続する方法自体は、Newell以来の統一理論や認知アーキテクチャの系譜にあり、新しくない。VPSYは、各研究の領分を抽象化してモジュールとして残し、インターフェースで接続する形で、調査の範囲ではまだ実装例のない分野群の組み合わせに適用している。

## 6. 現在地

- 要件定義の判断（D1〜D9）は決まった。主なもの：意識的な思考は内部で自律的に生成せず、外部情報のデータタイプとして入力する。睡眠は裏の処理として別のモジュールに分け、センチネル値のような特殊な値で表す。照合の前に、パラメータ復元と事後予測チェックを行う。
- 次の段階は、広範要求仕様と分解後要求仕様、その後に基本設計（傾向性の個人差の持ち方、TTLの長さと閾値など）と実装である。
- 開発範囲は最初から、個人としての感情シミュレーションに必要な全てとする。各層が互いの入力になる循環があり、一部だけ作ると照合の意味を失うためである。
